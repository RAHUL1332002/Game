# Snake Game 🐍

A classic Snake Game built using Python as a beginner programming project.

## Description
The player controls a snake, moves around the screen, and tries to eat food to increase the score while avoiding collisions.

## Features
- Snake movement using keyboard controls
- Food collection and score tracking
- Collision detection
- Game-over condition

## Technologies Used
- Python
- Turtle Graphics

## How to Run
1. Install Python 3
